# MyBlinkStyleClicker

An original C# WPF clicker project inspired by the UI screenshots you provided.
It does NOT contain BLINK's source code.

## Requirements
- Windows
- Visual Studio 2026
- .NET 10 SDK
- Visual Studio workload: .NET desktop development

Microsoft's WPF documentation:
https://learn.microsoft.com/en-us/dotnet/desktop/wpf/overview/

## Run
1. Open `MyBlinkStyleClicker.csproj` in Visual Studio.
2. Press F5.
3. F6 toggles the clicker.
4. Escape stops it.
5. Click Mode -> Hold makes F6 act as the held activation key.

## Current features
- Dark/red WPF interface
- CPS slider
- CDC slider
- Eco/Normal/Max UI
- Precision toggles
- Toggle/Hold modes
- F6 activation
- Escape emergency stop
- Win32 SendInput click engine
- Quick presets
- CPU/RAM panel placeholder

The next development step is replacing the navigation placeholders with the full Presets, Resolution, Tweaks, Optimizations, History, Theme, and Settings pages from your screenshots.
